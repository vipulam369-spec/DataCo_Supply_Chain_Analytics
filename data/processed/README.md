# Processed Dataset

This directory is reserved for the cleaned analytical dataset produced by the final project notebook.

## File \

`DataCoSupplyChainDataset.csv`

## Purpose

The processed dataset is the standardized analytical layer used for business analysis, Power BI reporting, and downstream project artifacts.

It is derived from the raw source dataset through the documented data audit, cleaning, transformation, and validation workflow in the final notebook.

## Repository note

The processed CSV is not committed to this repository because of its file size.

To reproduce it locally, place the raw dataset in `data/raw/` using the required project filename and run the final analytics and ML notebook.

## Downstream use

The processed dataset supports:

- Business analysis
- Power BI decision dashboard
- Predictive modeling
- Streamlit deployment
- Project report outputs
